================================================================================
                    DOCUMENTACIÓN DE LA API - SISTEMA ACADÉMICO
================================================================================

INFORMACIÓN GENERAL
-------------------
Base URL:         http://localhost:5000/api
Autenticación:    JWT (Bearer Token)
Formato:          JSON
Header requerido: Authorization: Bearer <token>

Todas las rutas excepto /auth/login requieren token JWT.
El token se obtiene haciendo login y se envía en el header Authorization.


================================================================================
                            AUTENTICACIÓN (/auth)
================================================================================

1. LOGIN
   Método: POST
   URL:    /api/auth/login
   Body:
   {
       "pro_email": "correo@ejemplo.com",
       "pro_password": "tu_password"
   }
   Respuesta (200):
   {
       "message": "Logueo exitoso",
       "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
   }


================================================================================
                            ACTIVIDADES (/actividad)
================================================================================

1. OBTENER TODAS LAS ACTIVIDADES
   Método: GET
   URL:    /api/actividad?page=1&limit=10&cadena=busqueda
   Respuesta (200):
   {
       "totalItems": 10,
       "totalPages": 1,
       "currentPage": 1,
       "limit": 10,
       "data": [ { "idactividad": 1, "act_nombre": "Docencia" } ]
   }

2. OBTENER ACTIVIDAD POR ID
   Método: GET
   URL:    /api/actividad/:id

3. CREAR ACTIVIDAD
   Método: POST
   URL:    /api/actividad
   Body:
   { "act_nombre": "Investigación" }

4. ACTUALIZAR ACTIVIDAD
   Método: PUT
   URL:    /api/actividad/:id
   Body:
   { "act_nombre": "Investigación Científica" }

5. ELIMINAR ACTIVIDAD
   Método: DELETE
   URL:    /api/actividad/:id

================================================================================
                            CÓDIGOS DE ESTADO HTTP
================================================================================

200 - OK                    : Operación exitosa
201 - Created               : Recurso creado
400 - Bad Request           : Datos inválidos
401 - Unauthorized          : Token inválido o expirado
404 - Not Found             : Recurso no encontrado
409 - Conflict              : Recurso duplicado o con dependencias
500 - Internal Server Error : Error del servidor


================================================================================
                            NOTAS IMPORTANTES
================================================================================

1. Todas las rutas excepto /auth/login requieren token JWT.
2. El token se obtiene haciendo login y se envía en el header
   Authorization: Bearer <token>.
3. Los parámetros page, limit y cadena son opcionales en las rutas de listado.
4. Los valores de los ENUM (como coo_rol, pro_tipo, pro_categoria) deben
   coincidir exactamente con los definidos en la base de datos.
